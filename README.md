# Noodles Store
Noodles Store is a Django-based web application for displaying and managing noodles products.
## Features
- View noodles products
- View product details
- Product names, descriptions and prices
- Product images
- Product categories
- Django admin panel for managing products
## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
## Requirements
The required Python packages are listed in `requirements.txt`.
## Environment
Project configuration and sensitive settings are managed using environment variables.
